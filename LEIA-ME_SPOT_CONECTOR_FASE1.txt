ETAPA A — CONFIGURAR CHAVE NOVA, SEM SALVAR NO HISTÓRICO DO SHELL
Solicite à SPOT a rotação da chave compartilhada na conversa. No SSH DA AWS,
execute estes comandos um por vez; ao executar o comando read, digite a chave
nova quando o terminal solicitar. A entrada fica oculta; não a cole no comando:

umask 077; mkdir -p /home/admin/.config/c4u; chmod 700 /home/admin/.config/c4u
read -r -s -p 'Nova Access Key SPOT: ' SPOT_KEY; echo
printf '%s' "$SPOT_KEY" > /home/admin/.config/c4u/spot-access-key; unset SPOT_KEY; chmod 600 /home/admin/.config/c4u/spot-access-key

O serviço PM2 deve rodar como usuário admin, como nas capturas anteriores.
A credencial deve permanecer FORA da pasta pública e do ZIP do projeto.

quantidades fixas do banco de DEMONSTRAÇÃO. O teste isolado SPOT acima não usa db.
Se houver falha, não continue: use o backup para restaurar com o servidor parado.

ETAPA D — VALIDAR NO NAVEGADOR
Entrar como ADMIN > Configurações / Integrações > painel SPOT.
1) Botão Testar autenticação: deve validar sessão. Se der erro, anote SÓ a mensagem,
   nunca o token, URL com accessKey ou a chave.
2) Selecionar Products, OptionalsComplete, Colors, Stocks e consultar prévia.
3) Conferir as colunas e exemplos de SKU, referência, nome, cor, preço e estoque.
4) Informar quais feeds são reconhecidos e quais campos recebidos sem dados sensíveis.
O conector não sincroniza produto nenhum nesta fase: mapeamento real precisa ser
validado para não duplicar imagens, trocar cores ou substituir preços errados.

PRIVACIDADE / SEGURANÇA
- Todos os endpoints exigem sessão autenticada e cargo Administrador.
- Chave não é armazenada no banco C4U nem incorporada no browser.
- HTTPS com domínio fixo e redirects desabilitados.
- Token apenas em memória do processo e renovação após até 20h / erro de sessão.
- A API usa parâmetros de query para autenticar. Não habilite logs de URLs
  completas de requisições externas; não compartilhe logs com tokens.
- O formulário HTTP aberto previamente sem chave retornou 200; NÃO implica
  que o acesso real esteja habilitado.
